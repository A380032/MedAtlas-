# ALVORA Med — tibbiy terminlar lug‘ati (O‘zbekcha → English)

Jami: 345 ta termin. Tarjimada shu lug‘at hamma joyda bir xil ishlatiladi.

## Tarjima qoidalari

1. **Imlo:** Amerika inglizchasi (hemoglobin, edema, anemia, esophagus) (tasdiqlangan).
2. **Ruscha shakldagi terminlar** standart inglizcha shaklga o‘tadi: gipo-/giper-/gemo- → hypo-/hyper-/hemo-, ts → c (atsidoz → acidosis), x → ch (xolesterin → cholesterol), -iya → -ia/-y (anemiya → anemia, gipertrofiya → hypertrophy).
3. **Qisqartmalar** inglizcha qisqartmaga almashadi: EKG → ECG, UTT → US, PZR → PCR, IFA → ELISA, ATF → ATP, KFT → GFR, YuIK → IHD, DVS → DIC, EGDS → EGD.
4. **Lotincha terminlar** (anamnesis morbi, rigor mortis, Rp., D.t.d.) o‘zgarishsiz qoladi.
5. **Dori nomlari** xalqaro nom (INN) bilan, keng tarqalgan boshqa nomi qavsda: Epinephrine (adrenaline), Paracetamol (acetaminophen).
6. **Sovet maktabiga xos tushunchalar** (distrofiya, anamnesis vitae, Nechiporenko, Zimnitskiy sinamalari) saqlanadi, kerak joyda G‘arbcha muqobili qavsda beriladi.
7. **Yodlash usullari** (mnemonikalar) so‘zma-so‘z emas, inglizcha ishlaydigan qilib qayta yoziladi; ma’lum inglizcha mnemonika bo‘lsa, shu olinadi.
8. **Raqamlar:** o‘nlik vergul nuqtaga almashadi (5,5 → 5.5); o‘lchov birliklari o‘zgarmaydi.
9. **O‘zbekistonga oid ma’lumotlar** (buyruqlar, milliy standartlar) tarjima qilinadi, lekin O‘zbekiston manbasi ekani saqlanadi. Abu Ali ibn Sino → Avicenna (Ibn Sina).
10. **Ilova nomlari:** ALVORA Med o‘zgarmaydi; Test markazi → Test center, Konsilium → Consilium.
